# ProCalendar.Maui - Product Roadmap

Build the most powerful, flexible, and performant calendar control for .NET MAUI, suitable for both simple applications and complex enterprise solutions.

## 🔄 Versioning Strategy

We follow [Semantic Versioning](https://semver.org/):

- **Major** (X.0.0): Breaking changes, major features
- **Minor** (0.X.0): New features, backward compatible
- **Patch** (0.0.X): Bug fixes, minor improvements

### Release Cycle
- **Major**: Yearly
- **Minor**: Quarterly
- **Patch**: As needed (typically monthly)
